### 🚀 Featured project

#### [`ask-jhony`](https://github.com/jhonyjss/ask-jhony) — privacy-first RAG demo (Nuxt 3)

> Chat with my CV. A working RAG app you can run with zero cost, zero risk.

The interesting part isn't the chat — it's the **architectural call**. Most public LLM demos bake in an API key and get drained by bots. This one is **BYOK** (visitor pastes their own OpenAI/Anthropic key) and runs **embeddings locally in the browser** via `@huggingface/transformers`. Hosting cost: **$0/month**.

**Stack:** Nuxt 3 · Vue 3 · TypeScript · `@huggingface/transformers` (WASM in-browser embeddings) · IndexedDB cache · OpenAI / Anthropic SDK-less streaming · Vercel · MIT.

→ **[Live demo](https://ask-jhony.vercel.app)** · **[Source](https://github.com/jhonyjss/ask-jhony)**
